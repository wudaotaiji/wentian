# 公開機能と制限

## 実装と稼働状態

Wentianには、OpenAI互換Gateway、モデル選択、外部Agent連携、グループ、プロジェクト知識庫、タスク実行、メディア制作、サイト制作、Personal Cloud等のコードが含まれます。実際の利用には、利用者がモデル、実行環境、接続先、権限を設定する必要があります。コードの存在だけでは、その環境での稼働・品質・容量を保証しません。

`/#improvements`は対応状況、`/#evidence`は保存された検証資料を表示します。履歴資料の成功と現在の実行環境の状態は別々に確認してください。個別機器の原始ログ・画像・内部受入記録は公開ソースへ含めません。

## CloudとWTC

| 対象 | 実装範囲と未完了条件 |
|---|---|
| Personal Cloud | PC登録、署名通信、Docker／Podman配備経路。複数実機、公開経路、永続データ、バックアップ復元等は環境ごとの検証が必要 |
| ノード連合 | 初期のノード識別、署名通信、ゼロ価格の計算注文とA2A。NAT、履歴の完全同期、多者取引、失効伝播などの本番運用は未完了 |
| Kubernetes／VM | 個人Cloudのコンテナ実行と独立した追加実行基盤。クラスタ作成・接続・仮想マシン管理の全面統合を完了扱いにしない |
| WTC | 発行契約は別プロジェクトで管理。Gatewayのウォレット接続は主ネット発行、流動性、実通貨への換金、注文の自動決済の完了を意味しない |

利用方法は[Personal Cloud](personal_cloud_implementation.md)、[ノード連合](decentralized_cloud_implementation.md)、[ウォレット](wallet_integration.md)を参照してください。

## その他の注意点

- メディア処理はモデルのライセンス、利用可能メモリ、GPU、品質評価が必要です。生成ジョブ成功だけで成果物の意味的品質を合格にしません。
- 会議のカメラ・音声・TURN・遠隔入力は端末、経路、利用者の同意に依存します。
- 有償注文・外部副作用を伴う実行の結果不明時には、自動再送せず状態照合を優先します。
- 公開サンプルは合成データを使用し、秘密設定・実利用データを試験用に変更しません。

## 公開資料の範囲

詳細な内部設計や事業方針を非公開にしても、公開インターフェース、構築手順、制限は公開側で説明します。公開済み資料と実装に不一致があれば、対象バージョンと再現手順を添えて報告してください。

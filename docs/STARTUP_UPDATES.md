# 起動時の更新確認

対話端末で `wentian`、`wentian agent`、`wentian resume`、`wentian web` を起動すると、インストール元の現在ブランチと `origin` の同名ブランチを比較します。パッケージのバージョン番号が同じでもコミットが異なれば更新を通知します。

更新可能な場合は **Enter キー1回**で更新できます。`n` を入力して Enter を押すと延期し、そのまま起動します。後から `wentian update` でも確認・更新できます。

未コミット変更がある場合は更新を適用できません。先に変更をコミットするか退避してください。通信失敗やリモートブランチが存在しない場合は、確認できなかった旨を表示して起動を続けます。リモート確認のタイムアウトは5秒です。

更新には既存の更新処理を使います。対象コミットを再確認し、fast-forward、`npm ci`、型検査、自動テスト、稼働中の Gateway の再起動を行います。結果は `.wentian/updates/` に記録します。更新後は Wentian を再起動してください。更新失敗時も旧コードの実行を終了し、エラーと復旧記録を表示します。

パイプ入力・非対話実行、ヘルプ、診断、サーバー・デーモン管理では起動時確認を行いません。非対話での `wentian update` は更新計画の表示だけを行います。既存の `/update` とトークンによる更新も利用できます。

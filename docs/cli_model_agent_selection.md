# CLIのモデル・外部Agent選択

## 操作仕様

| コマンド | 動作 |
| --- | --- |
| `/model` | 接続先Gatewayの`/v1/models`からモデル一覧を取得して選択待ちにする |
| `/model MODEL_ID` | 登録モデルを直接指定する |
| `/agent` | このPCの外部Agent台帳から一覧を表示して選択待ちにする |
| `/agent AGENT_ID` | 外部Agentの優先使用を保存する |
| `/agent auto` | 外部Agentの優先指定を解除する |

一覧は現在の項目、モデル名・Agent名、ID、状態を表示する。上下キーで選ぶと入力欄へ選択コマンドが入り、Enterで確定する。番号・IDの入力、空入力で現在の選択の確定にも対応する。利用不可項目を上下キーでは飛ばし、番号やIDで指定された場合も拒否する。EscまたはCtrl+Cは選択だけを取り消し、会話を終了せず、設定を変更しない。端末の通常履歴は選択中の上下キーへ介入させない。

外部Agentは実行対応、除外設定、接続の有効性、会話失敗後の再試行待ちを検査する。会話の選択可能性と、読取・編集・試験などの業務能力検証は別とし、選択によって業務検証を迂回しない。優先指定はWeb画面と同じ管理ファイルを使う。これは候補の優先順位であり、失敗・権限・予算などの制約を無視した排他的な強制実行ではない。

Gatewayモデルを選ぶと既存の外部Agent優先指定を解除する。選んだモデルが次の要求へ反映されず、以前のAgent優先だけが残る状態を避ける。TTYの対話SessionにはモデルIDを保存し、同じSessionをresumeした際にも使用する。新規Sessionの起動既定値や外部Agent自身の設定モデルは変更しない。外部Agentのモデル変更は既存のWeb側のモデル設定で行う。

モデル一覧取得は既存のAPIキー環境変数を利用するが、秘密値を表示しない。モデル一覧を取得できない、指定IDがない、または利用終了の場合は選択を変更しない。モデルの「登録済み」は現在の接続成功を保証する表示ではない。

パイプ入力のCLIでも同じコマンド・番号・ID指定を利用できる。パイプ入力には上下キーによる選択はない。EOF後は閉じたreadlineへプロンプトを描画しない。

- TypeScript型検査が成功。試験ログはローカル`.wentian/terminal-selection-*.log`に保持する。

# 人間同士の個別チャットと参加者管理

2026-10-19

## 個別チャット（DM）

左メニューの「個別チャット」、または群の人間メンバーの「個別チャット」から `/direct-messages` を開く。登録済み・有効な利用者を一人選び「会話を開く」で開始する。新着と会話一覧は表示中に3秒ごとに更新する。中日英の選択と共通ナビゲーションを使用する。

ログイン済み本人を送信者として扱い、クライアントからの送信者IDを採用しない。同じ二人の会話は一つにまとめる。会話の一覧・取得・送信は当事者二人だけが利用でき、管理者にもDM APIの閲覧特権を設けない。無効化した利用者を含む会話への新規送信は拒否する。

群履歴や公開ページへ転載せず、AI応答・書斎への成果物保存の処理にも渡さない。本文はHTMLとして解釈しない。1投稿は1～10,000文字。サーバー作業場所の `.wentian/direct-messages/` に保存し、同時送信はファイルロックと原子的置換で保護する。サーバー管理者が保存ファイルを読むことまで防ぐ仕組みではなく、エンドツーエンド暗号化ではない。ゲストには登録アカウントがないためDMは利用できない。

APIは `GET/POST /api/direct-messages`、`GET /api/direct-messages/:id`、`POST /api/direct-messages/:id/messages`。本文一覧は会話取得時だけ返し、一覧APIには含めない。認証失効時は画面の履歴を隠し、ログインへ案内する。

## 発言禁止・強制退会

群の人間メンバー欄に、管理者だけが操作できる次のボタンを追加する。

| 操作 | 動作 |
|---|---|
| 発言禁止 | 閲覧・在籍は維持し、群への新規投稿を拒否する |
| 発言禁止を解除 | 新規投稿を再許可する |
| 強制退会 | 在籍を解除し、オフラインにして再参加を禁止する |
| 参加禁止を解除 | 再参加を許可する。自動で在籍へ戻さない |

ミュートは退出・再参加で解除しない。本人への管理操作は禁止。確定済みの発言履歴を削除せず、管理操作の実行者・対象・日時を群の `.humans` 台帳に記録する。AI議論の保存とは別の人間専用ロックを使い、設定を再起動後も維持する。

`POST /api/workbench/groups/:id/moderation` に `userId` と `action: mute | unmute | kick | unban` を渡す。一般利用者はAPIを直接呼んでも操作できない。投稿・再参加時に保存状態を検査するため、画面のボタンを回避しても禁止が適用される。公開ページからのゲスト投稿にも同じ制約を適用する。

ゲストの識別は訪問者Cookie単位。Cookie削除や別ブラウザーで新規訪問者となる場合まで同一人物を特定するものではない。確実にアカウント単位で管理したい公開群は「ログイン必須」を選ぶ。群での措置はDMや別の群の権限を変更しない。強制退会は既存の公開ページの閲覧権限を変更する操作ではない。

## 検証

一時領域と架空利用者で、二者間送受信・同時投稿の保持・第三者と管理者の拒否・公開群とAIへの非混入・外部オリジン拒否・入力制限・認証失効時の非表示を検証する。管理機能では一般利用者の拒否、ミュートの再参加後の維持、解除、強制退会後の再参加拒否、ゲストへの適用と再読込後の保持を確認する。本番群へ試験投稿せず、本番利用者を退会させない。

型検査成功、関連53試験成功（失敗0、スキップ0）。サーバーを再起動して機能を反映した。

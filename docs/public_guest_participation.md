# 公開ページのゲスト参加

2026-10-19

公開参加を「許可」にした群では、訪問者が名前とメールアドレスを入力するだけで発言できる。アカウント登録・ログインは不要。入力形式は `名前<メールアドレス>`。名前は公開し、メールアドレスと投稿元IPは公開レスポンスへ含めない。メールアドレスは自己申告であり、所有確認は行わない。

公開設定の「許可／禁止」はページ別に維持する。禁止された群の参加・投稿はサーバー側でも拒否し、既存の禁止設定を自動で許可へ変えない。管理画面は「公開と閉鎖」内の「公開ページからの人間参加」で変更する。

ゲスト識別には群・公開ページ別の署名付きCookieを使う。有効期間は24時間、HttpOnly・SameSite=Laxを設定し、HTTPSではSecureも設定する。署名鍵は作業場所の `.wentian/public-guests/session.key` に保存し、再起動後も検証できる。ゲストCookieは管理者ログインや内部APIの認証には使わない。

投稿頻度は群・IP別で既定12件／分。利用者設定 `WENTIAN_PUBLIC_GUEST_POSTS_PER_MINUTE` で1～120件に変更できる。制限はプロセス内で管理し、再起動時にリセットする。外部オリジンからの投稿を拒否し、本文は1～10,000文字に制限する。

ゲスト発言も既存の人間発言と同じAI応答キューへ渡す。AIが利用可能な場合、群の自律討論・人間発言への応答設定に従って返答する。投稿結果には受付状態だけを返し、内部の参加者情報を返さない。

## 検証

型検査成功。ゲスト参加、投稿保存、AI返答、公開情報からの個人情報除外、改変Cookie・別ページ・外部オリジン・内部管理操作の拒否、公開参加禁止、入力形式・頻度制限を隔離環境で確認した。関連試験35件成功。本番の群には試験投稿していない。

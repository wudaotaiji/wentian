# サイト一覧・テンプレート作成・公開リンク

- `http://127.0.0.1:8787/#site` の上部へ「作成済みサイト一覧」を追加。保存データから一覧を更新し、編集ボタンと公開リンクを表示する。
- テンプレート（Template）から作成後、新しいサイトを選択し、入力欄とプレビュー（Preview）を読み込む。進行状況とエラーをテンプレートの近くにも表示する。
- 作成時のURL入力は英小文字へ統一する。`Iceberg` と入力した場合、公開リンクは `/sites/iceberg/` になる。`/sites/Iceberg/` でも同じサイトを表示する。
- 公開ページと公開API（Application Programming Interface）は管理画面と同じポートで提供する。従来の80番ポートと `/pages/` は引き続き利用できる。
- 保存後は一覧を再取得し、サイト名と公開リンクを更新する。

## 検証

- 型チェック（Type Check）成功。
- 関連する10件の自動テスト（Automated Test）成功。テンプレートのクリック、編集準備、公開URL、大文字別名、未作成サイトの404応答を含む。
- 一時領域と8788番ポートの検証用サーバーで、実ブラウザー（Browser）によるテンプレート作成・保存・一覧リンクからの公開表示を確認。ブラウザー内のエラーは0件。
- 既存のソース書き出し、モバイル表示、外部ファイルの編集・バックアップ（Backup）、検証用サイトの削除も確認。
- 8787番サーバーを再起動して反映し、配信HTMLの一覧機能と公開APIの応答を確認。セッション（Session）は再起動で失効するため再ログインが必要。
- 実運用の認証値ではログインできなかったため、8787番でのログイン後の操作は未検証。上記の一連の操作は分離した検証用環境で確認した。

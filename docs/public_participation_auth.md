# 公開群の参加認証方式

群の「公開と閉鎖」から、公開ページごとに次の3方式を選び、「公開」または「参加設定を保存」で反映する。

| 選択 | 公開ページの動作 |
|---|---|
| 禁止（閲覧のみ） | 参加・投稿不可 |
| 許可（ゲストも参加可能） | 名前とメールアドレスの入力で投稿可能。登録・ログイン不要 |
| 許可（ログイン必須） | 登録済みWentianアカウントのユーザー名・パスワードで認証して投稿 |

アカウントの一般公開登録機能は追加しない。必要なアカウントは既存の利用者管理で用意する。名前とメールアドレスの入力は両方式で必要で、メールアドレスは非公開。

保存値は既存の `showComposer` と、新しい `participationAuth: guest | login`。認証方式未指定の既存群はゲスト方式を維持し、説明更新では保存済みの方式を保持する。他ページの設定を変更しない。公開ページは認証方式変更も定期取得で検知し再読込する。

ログイン必須では、ゲスト投稿経路を使わず既存の認証付き参加・投稿APIへ転送する。ゲストCookieだけでは参加できない。画面表示だけでなく、直接APIへの投稿も同じ制約を受ける。

隔離試験でゲストCookieの拒否、ログイン済み利用者の投稿、設定保持、管理画面からの方式保存を検証する。本番群への試験投稿は行わない。型検査と関連試験21件は成功。

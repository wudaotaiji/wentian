# サイト別ソースの保存

## 外部サイト・削除・テンプレート

「外部フォルダー・Apacheサイトを編集」で、このPCからアクセスできるサイトの絶対フォルダーパスを入力し、ファイルを選んで直接編集できます。UTF-8のHTML・CSS・JavaScript・JSON・テキスト・Markdown・SVG・PHPが対象です。フォルダー一覧は5階層・500ファイルまで、編集ファイルは512 KiBまでです。隠しファイル・リンク・複数ハードリンクは対象外です。外部サーバーへSSH接続する機能ではありません。

保存前に `.wentian/site-file-backups/<一意ID>/` へ原本と元パスを保存します。外部で変更されたファイルは上書きせず、再読込を案内します。HTMLのプレビューはスクリプトを実行せず、PHPの実行と相対パス素材を含む完全な表示確認はApache側で行います。フォルダー接続は30分で失効します。

「このサイトを削除」は確認後に管理ページと生成ソースを `.wentian/site-trash/<一意ID>/` へ移動します。追加ページは公開一覧から外れ、トップページは既定の保存前状態に戻ります。外部Apacheフォルダーや共有相談室は削除しません。ゴミ箱のmanifest.jsonに元のパスを記録します。

完成済みテンプレート（Template）は Aurora AI、Atelier Studio、Maison Luxe、Horizon Business の4種類です。「このデザインで作成」で新しいページとソースを生成します。ページURLと名前を空欄にした場合は自動設定します。同名サイトを上書きしません。テンプレートには不要な相談室領域を表示せず、サービス紹介と問い合わせ導線を用意しています。問い合わせ先などの実情報は公開前に編集してください。

検証: 関連テスト20件に加え、PythonのPlaywrightによるEdge実画面検証でテンプレート複製、単独HTML・モバイル表示、Apache原本編集・バックアップ、サイト削除を確認しました。証拠は `docs/evidence/20261006_site_editor/` に保存します。

サイト制作で「保存してページを公開」を押すと、公開用の設定に加えて独立した静的サイトのソース（Source）を生成します。AI案の自動保存、新しいページの追加でも同じ処理を実行します。

標準保存先は `C:\workspace\wentian-gateway\.wentian\sites\home\revision-<版>-<一意ID>\` です。追加ページは `.wentian\sites\pages\<ページ名>\revision-<版>-<一意ID>\` へ保存します。`WENTIAN_TASK_WORKSPACE` が設定されている場合は、そのフォルダーを起点にします。毎回新しい世代を作り、前回のファイルを保持します。

| ファイル | 内容 |
| --- | --- |
| index.html | 単独で表示できるページ |
| styles.css | ページ全体のスタイル |
| site.json | 再編集用のページ設定 |
| README.md | 表示方法と含まれる機能の説明 |

画面に保存先を表示します。「保存済みソースを書き出す」は保存済みの設定だけを使い、未保存のプレビューは反映しません。生成した `index.html` と `styles.css` は同じフォルダーに置いて開くか、静的ホスティング（Static Hosting）へ配置できます。外部画像などURL参照の素材はダウンロードしません。

公開相談室の履歴、ログイン、投稿、自動更新は書き出しに含めません。任意のサーバーアプリやデータベースの実装を生成する機能ではなく、現在のサイト制作で編集した静的ページ一式を保存する機能です。

管理者認証と同一オリジン（Same Origin）の制約は既存の保存APIと共通です。書き出しAPIは `POST /api/site-admin/export?page=<ページ名>` です。保存先の途中にシンボリックリンク（Symbolic Link）がある場合は生成を拒否します。公開設定の保存後に生成が失敗した場合は、設定保存の成功とソース生成の失敗を分けて画面へ表示し、再書き出しで再実行できます。
